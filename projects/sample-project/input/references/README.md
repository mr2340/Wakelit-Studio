# Reference Assets Directory

Place your character and visual style reference images here.

### Expected Files:
- `master-character.png` (or `.jpg`): The primary character visual anchor sheet.
- Optional secondary character views (e.g. `character-ribbon-teal.png`, `character-expressions.png`).
- Visual style anchors (e.g. `lighting-reference-01.png`, `environment-reference-01.png`).

These references are attached and linked in Google Flow prompts and scene queue schemas.
